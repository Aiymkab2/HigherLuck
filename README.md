# HigherLuck

## Description
HigherLuck is a two-player dice game developed in C# using Windows Forms.

## Features
- Two players with customizable names and avatars
- 5–30 rounds per game
- Random dice rolling (1–6)
- Automatic score calculation
- Winner announcement
- Save and display game results
- Reset game functionality
- Exception handling

## Game Rules
Each player rolls the dice once per round. The player with the higher number earns one point. In case of a tie, both players earn one point. The player with the highest score wins.

## Technologies
- C#
- .NET 8.0
- Windows Forms
- Visual Studio

## How to Run
1. Open the project in Visual Studio.
2. Build the solution (`Ctrl + Shift + B`).
3. Press `F5` to start the game.
